# law-chain-reaction — «Цепная реакция»

**Закон метода:** одно касание — дальше всё само. Машина Голдберга на офисном столе: палец толкает одно домино, и каждое следующее событие физически вызвано предыдущим. Камера снимает всё одним непрерывным планом, без склеек, а каждый удар звучит нотой джингла. Машина собрана из партитуры: зазоры домино и места брусков ксилофона рассчитаны так, чтобы удары падали на сетку 16-х долей.

Ролик: 19.2 с, 1920×1080, 30 fps, 112.5 bpm, 9 тактов. Последний такт — бесшовная петля.

## Что умеет
- Хук на первом домино («ОДИН / КЛИК»).
- Цепочка этапов с физическими подписями: ЗАЯВКА → CRM → СЧЁТ → ОПЛАТА → АВТОПИЛОТ.
- Шарик играет мелодию на ксилофоне.
- Монета залетает в копилку, вентилятор запускает бумажный самолётик, тот тапает «Подписаться» на телефоне.
- Поле из 35×9 домино падает и открывает пиксельный логотип.
- Рулон бумаги разворачивается со слоганом и ссылками.
- Музыка синтезируется в JS, каждый удар машины стоит на сетке.
- Детерминированный рендер (three.js r180 в headless Chromium) и проверка гейтом.

Работает на конвейере procedural-film из этого плагина (`skills/procedural-film/SKILL.md`). Общие заметки по серии — в `skills/aixenix-video/SKILL.md`. Подробности на английском — в `SKILL.md` рядом.

## Как поставить и сделать свой ролик
```bash
cp -R skills/law-chain-reaction/example my-chain-ad   # имя папки = slug ролика
cd my-chain-ad
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs      # гейт: exit 0 = зелёный
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --times 0.9,13.4,17.6 --scale 0.5 --sheet --out .frames/look
zsh deliver.sh                                          # мастер, web, луп, постер, dist/<slug>.html
```
Нужен ffmpeg в PATH. Один кадр рендерится примерно за 0.4 с, весь ролик — 4–5 минут в 3 потока.

## Где править тексты и бренд
- **Хук:** `src/scenes/01-world.js` → холст большого домино, строки `'ОДИН'` и `'КЛИК'`.
- **Логотип-мозаика:** `src/scenes/01-world.js` → `mosaic()`, строка `const word = 'AiXenix'`; буквы задаёт таблица `GLYPH` (7 строк). Размер поля — `FD.cols` / `FD.rows` в `src/scenes/00-phys.js`.
- **Слоган и ссылки на рулоне:** `src/scenes/01-world.js`, блок баннера: `'Бизнес на автопилоте'`, `'aixenix.com'`, `'t.me/aixenix'`.
- **Экран телефона:** там же — `'t.me/aixenix'`, `'ИИ-инструменты'`, `'каждый день'`, `'Подписаться'`.
- **Подписи этапов:** `dymo('CRM')`, `dymo('ОПЛАТА')`, `dymo('АВТОПИЛОТ')`, стикер `'СЧЁТ'`, табличка `'ЗАЯВКА'`.
- **Цвета:** `PAL` в `01-world.js`; грейд и виньетка — `COMP_FS` в `src/scenes/02-film.js`.
- **Мелодия:** `MELODY` — одинаково в `00-phys.js` и `src/music.js` (бруски ксилофона переставятся сами).
- **Темп и тайминг событий:** `BPM` и `N` в `00-phys.js`, `src/timeline.js`, а также времена в `src/music.js`. Камера (`K` в `02-film.js`) задана в секундах — её нужно переложить вручную.

После правок прогоните гейт и посмотрите контакт-лист. Копии сцен в `tools/fixtures/chain-hero/scenes/` обновляйте вручную.
