# law-oscilloscope — «Осциллограф: звук рисует картинку»

## Закон

Всё, что светится на экране, — след ОДНОГО электронного луча векторной ЭЛТ. Отклонение по X —
левый канал саундтрека, по Y — правый. Что слышишь, то и видишь: картинка и звук считаются один
раз из одного массива сэмплов (`FILM.osc`). Кроме луча в кадре только сам прибор: рамка,
градуировка, блик стекла, ручки и два входа — голубой кабель (L) в гнезде X, пурпурный (R) в
гнезде Y, у каждого диод, горящий от своего канала. Если подать звук готового MP4 на настоящий
осциллограф в режиме X-Y, он нарисует этот же фильм.

## Что умеет

- Пишет лучом слова (однолинейный векторный шрифт, кириллица + латиница), рисует фигуры, шестерни,
  руки, график, бумажный самолётик.
- Фигура, обведённая f раз в секунду, — нота высоты f; фигуры Лиссажу p:q — музыкальный интервал;
  бочка — расходящееся кольцо, трясущее картинку; хэты и малый — «шум» трассы.
- Физика настоящего прибора: яркость ∝ времени луча в точке, бледные линии обратного хода,
  двухслойный люминофор с послесвечением, ореол в стекле, выпуклость экрана.
- 1920×1080, 30 fps, 22,4 с, последний такт — бесшовная петля; звук ≈ −16 LUFS без обработки.

## Как поставить и сделать свой ролик

Нужны Node 18+, zsh и ffmpeg. Из папки плагина:

```bash
cp -R skills/law-oscilloscope/example my-ad && cd my-ad
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs        # гейт: код 0, WARN допустим
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --times 1.6,10.9,19.9 --out .frames/look --scale 0.5
zsh deliver.sh                                            # мастер, web, петля, постер, HTML
```

Результат — в `exports/` (`<slug>.mp4`, `-web.mp4`, `-loop.mp4`, `-poster.jpg`) и `dist/<slug>.html`.

## Где править тексты

Все пути — внутри `example/`.

- Финальная карточка: `src/cast.js`, функция `card()` — строки `'AiXenix'`,
  `'БИЗНЕС НА АВТОПИЛОТЕ'`, `'aixenix.com'`, `'t.me/aixenix'`, их размер и высота.
- Хук и слоган: `src/cast.js`, функция `cast()` — `hook` («СЛУШАЙТЕ КАРТИНКУ»), `sl1`/`sl2`
  («БИЗНЕС / НА АВТОПИЛОТЕ»), `brandBig` (крупное имя).
- Нет нужной буквы — добавить глиф в таблицу `G` в `src/props.js` (иначе символ станет пробелом).
- Музыка: ветки внутри `compute()` в `src/cast.js` (массивы частот `pat(...)`, `KNOTS`,
  `buildDrums()`); частоты обводки текста держать кратными 30 Гц, чтобы буквы не «плыли».
- Цвета люминофора — объект `GREEN`, цвета кабелей и диодов — вызовы `jack(...)`/`led(...)` в
  `src/props.js`. Громкость — `GAIN` в `src/music.js` (на картинку не влияет).

Подробности для агента — в `SKILL.md`; общий конвейер — `skills/procedural-film/SKILL.md`.
