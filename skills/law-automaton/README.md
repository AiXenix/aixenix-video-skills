# law-automaton — «Автоматон 1774»

**Закон:** на экране не появляется ничего, чего не сделала машина. Часовой андроид-писец из латуни
и фарфора (по мотивам «Писца» Жаке-Дро, 1774) пишет каждое слово гусиным пером. Его рукой управляют
латунные кулачки, и профиль каждого кулачка вычислен из траектории пера по буквам. Получается, что
форма кулачков и есть написанный текст. Рука, чернила и даже скрип пера в саундтреке считываются с
этих профилей.

## Что умеет

- Ролик 1920×1080, 30 fps, 24 с (15 тактов при 150 bpm), последний такт — бесшовная петля.
- Сюжет: завод ключом → пуск, перо выходит из чернильницы → хук «Автоматизация с 1774» →
  вид сквозь стеклянную спину (кулачки вращаются, щупы скользят по профилям, тикает анкер) →
  «Бизнес на автопилоте» → макро «AiXenix — теперь с ИИ» → «aixenix.com» и самолётик с
  «t.me/aixenix» → финальная плашка: сам исписанный лист.
- Чернила настоящие: свежие блестят и сохнут, на нисходящих штрихах нажим, при касании пером
  остаётся клякса.
- Музыка синтезирована в коде: клавесин, музыкальная шкатулка, тик-так спуска на каждую восьмую,
  «клац» стопки кулачков на склейках.
- Работает на конвейере procedural-film из этого плагина (`skills/procedural-film/SKILL.md`).
  Общие заметки — в `skills/aixenix-video/SKILL.md`.

## Как поставить и сделать свой ролик

Нужны node 18+, ffmpeg и zsh. Команды запускаются из корня плагина:

```bash
cp -R skills/law-automaton/example my-ad && cd my-ad     # имя папки = slug файлов
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs         # гейт: exit 0 (WARN по цене кадра — норма)
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --samples 24 --sheet --scale 0.5
zsh deliver.sh                                            # мастер, web, loop, постер, dist/*.html
```

Рендер идёт программно (SwiftShader): около 0,3 с на кадр на свободной машине, около 1 с под нагрузкой.

## Где править

- **Тексты** (хук, слоган, бренд, адреса): `src/props.js` → массив `CARDS`. Одна карта — один оборот
  кулачкового вала, у каждой строки есть `text`, `x`, `y`, `size`. Если меняете число карт, правьте и
  `NREV`.
- **Новая буква**: `src/props.js` → `def('буква', ширина, штрихи)`. Если буквы нет, загрузка падает с
  ошибкой `no glyph for`.
- **Размер почерка и лист**: `XH`, `SLANT`, `PAGE`, `PAGE_C` в `src/props.js`.
- **Цвета**: `src/cast.js` → `M.velvet` (камзол), `M.brass`, `M.camBrass`, `M.porcelain`; цвет
  чернил задают `wetC`/`dryC` в `inkMaterial`.
- **Темп и длительность**: `BPM`, `REV` в `src/props.js`, тайминги в `src/timeline.js`, `BEAT` в
  `src/music.js`.
- **Музыка**: `src/music.js` → `CH`, `PROG`, `MEL`, функция `score()`.
- **Камеры**: `src/scenes/01-…08-*.js`, кадр финальной плашки задаёт `FILM.CARD_CAM` в
  `src/scenes/07-card.js`.
