# law-splitflap — «Табло вылетов»

**Закон:** всё на экране показывает только механическое табло Solari. Это 504 модуля, у каждого барабан из 75 лепестков.

- Текст набирается лепестками-буквами.
- Картинки собраны мозаикой: на каждом лепестке напечатан только свой фрагмент кадра.
- Модуль листает строго по одному лепестку. Чтобы дойти до нужной буквы, он прощёлкивает все промежуточные.
- Щелчки лепестков — это ритм саундтрека.

Пример в `example/` — готовый 21-секундный ролик AiXenix «Бизнес на автопилоте»: рейсы «РУЧНОЙ ВВОД — ОТМЕНЁН» → шторм букв → мозаика взлёта → «РЕЙС AIXENIX · ВЫЛЕТ: СЕЙЧАС» → плашка с логотипом, сайтом и Telegram.

## Что умеет

- Модули настоящие: верхняя половина буквы падает на оси и отскакивает, видна тень и линия сгиба.
- Модули работают вразнобой, кадр сделан с motion blur.
- Анимация картинок — флипбук: каждый переворот лепестка двигает кадр.
- Логотип собирается мозаикой, сайт и Telegram набираются буквами.
- Музыка синтезируется из того же расписания, по которому падают лепестки. Около 40 тысяч щелчков настроены по аккорду и разведены по стерео.
- Всё детерминировано. Гейт пайплайна procedural-film зелёный.

## Как поставить и собрать свой ролик

Нужны Node 18+, ffmpeg и zsh.

```bash
cp -R example my-board && cd my-board
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs          # гейт: exit 0, WARN допустим
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --samples 24 --sheet --scale 0.5 --out .frames/sheet
FILM_NO_NET=1 zsh tools/q.sh node tools/render.cjs         # exports/my-board.mp4
zsh tools/deliver.sh                                       # web-версия, петля, постер, HTML-плеер
```

На macOS рендер идёт на видеокарте (ANGLE Metal), это быстро. На Linux и Windows — программный SwiftShader, это медленно: для черновиков ставьте `--scale 0.5`. Переключатель — переменная `FILM_GL=swiftshader|metal`.

## Где править

- **Тексты на табло:** `src/cast.js` → `LAYOUT` (заголовок, строки рейсов, девиз, строка рейса, сайт, выход). Сетка — 36×14 символов. Допустимы только символы с барабана: `CHARS`, латиница-двойники через `HOMO`.
- **Когда что садится:** `src/cast.js` → `SCRIPTS.film`, время задаётся через `b(такт, доля)`. `land()` — посадить ровно на долю, `go()` — запустить и дать осесть, как на настоящем табло.
- **Логотип, цвета, самолётик на плашке:** `src/scenes/01-board.js` → `drawCard()`. Цвета лепестка и краски — `FLAP_HEX`, `INK_HEX`.
- **Картинка взлёта:** `drawSky()`, `airliner()`, `PLANE`, `MOON`.
- **Камера:** `CAMK`.
- **Темп и длительность:** `src/timeline.js` (`bpm`, `duration`, `cues`). Длительность — целое число тактов.
- **Музыка:** `src/music.js` → `CH`, `BARS`, `MIX.ride`, `clatterRide()`, `score()`.

Подробности, ловушки детерминизма и устройство движка — в `SKILL.md`.
