# law-watercolor — «Растёт само» (акварель по-мокрому)

**Закон метода:** ничего не рисуется рукой. На бумагу ложится чистая вода (мокрая бумага чуть темнее и
блестит), падает одна капля пигмента — и цвет сам распускается и бежит по мокрым дорожкам. Так рождается
всё: буквы, ветви, иконки, логотип, бумажный самолётик. Под каждым словом мокрая нить: одна капля в её
начале заполняет всё слово, цвет поднимается в буквы снизу.

Готовый пример в `example/` — рекламный ролик AiXenix «Бизнес на автопилоте»: 21,3 с, 1920×1080, 30 fps,
8 тактов по 90 bpm, последний такт — бесшовная петля для фона сайта. Каждый пиксель и каждый звук
посчитан в JavaScript, без видеогенераторов и чужих картинок.

## Что умеет движок

- Растекание по-мокрому с перистыми краями, остановку цвета с тёмной кромкой.
- Затёки («цветная капуста»), кольца высыхания, грануляцию в зерне бумаги, звёзды от соли.
- Субтрактивное смешение цветов (жёлтый + синий = зелёный), лессировки.
- Дождь из капель в долю, наклон листа — пигмент стекает ручьями вниз.
- Бумагу «торшон» с рельефом и блеском мокрых мест; детерминированный кадр (одинаковый при любом порядке).

## Как поставить

Нужны Node 18+, ffmpeg, zsh.

```bash
cp -R example ../../my-watercolor-ad && cd ../../my-watercolor-ad   # имя папки = имя ролика
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs          # гейт: код 0 — зелёный
FILM_NO_NET=1 zsh tools/q.sh node tools/render.cjs         # exports/<папка>.mp4 с музыкой
zsh tools/deliver.sh                                       # web, петля, постер, dist/<папка>.html
```

Посмотреть весь ролик одним листом:
`FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --samples 24 --sheet --scale 0.25` (кадры в `.frames/`).

## Как сделать свой ролик

- **Тексты** — `src/cast.js`, объект `TEXT` в начале файла: хук, две строки слогана, логотип, сайт,
  Telegram. Размеры — `SIZES`, места — `CARD` и `HOOK`.
- **Иконки схемы** — `NODES` (вид, место, цвета, момент) и формы в `ICON`.
- **Цвета** — пигменты `PIG` и цвет бумаги `PAPER_RGB` в `src/props.js`.
- **Темп и длина** — `src/timeline.js` (`bpm`, `duration`, шоты, `cues`) и сетка времени в начале
  `src/cast.js` (`T_DROP`, `T_HUB`, `T_SLOGAN`, `T_TILT`, `T_CARD`, `T_LOOP`).
- **Камера** — `CAMKEYS` в `src/cast.js`.
- **Музыка** — функция `score()` в `src/music.js`; каждый удар совпадает с каплей на экране.

После правок — снова гейт и лист кадров; подробности на английском в `SKILL.md`.
Пайплайн — `skills/procedural-film`, общие заметки серии — `skills/aixenix-video`.
