# law-murmuration — «Мурмурация»

**Закон метода:** ничего не нарисовано — каждая фигура и каждая буква это силуэт живой стаи из 30 000
скворцов на закате. Птицы не перестают быть птицами: машут крыльями, планируют, кренятся, по стае бегут
тёмные волны. Тысячи отдельных решений складываются в одну умную форму — «бизнес на автопилоте».

## Что умеет

- Открывающая мурмурация над городом: живой складывающийся «лист» птиц с тёмными складками.
- Стая перестраивается в текст (хук, слоган, финальная плашка с адресами), шестерни, стрелку роста,
  бумажный самолётик, который летит и «пишет» плашку, роняя птиц.
- Каждая птица сохраняет себя от фигуры к фигуре; переходы — полёт, а не морфинг точек.
- Последний такт — бесшовная петля. Музыка синтезируется: хор, шорох крыльев, пульс-взмахи, удары на событиях.
- 1920×1080, 30 fps, 90 bpm, 21,3 с; гейт детерминизма зелёный.

## Как поставить

Работает на конвейере procedural-film из этого же плагина (`skills/procedural-film/SKILL.md`).

```bash
cp -R example/ ~/my-murmuration && cd ~/my-murmuration
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs          # гейт: exit 0 (WARN по цене кадра — норма)
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --samples 24 --sheet --scale 0.25
FILM_NO_NET=1 zsh tools/q.sh node tools/render.cjs --workers 4
zsh deliver.sh                                              # web, петля, постер
FILM_NO_NET=1 node tools/build.cjs                          # dist/<папка>.html
```

Перед первым кадром стая просчитывается целиком (~5 с) — это нормально.

## Как сделать свой ролик

Все правки — в папке-копии `example/`:

- **Тексты:** `src/cast.js` → `FL.SCRIPT.formations`, вызовы `textPainter('…')`:
  хук (`id: 'hook'`), слоган (`id: 'auto'`), плашка (`id: 'card'`: бренд, слоган, сайт, Telegram).
- **Адреса** ещё раз измеряются в `cardLayout()` того же файла — менять в обоих местах.
- **Шрифт:** константа `FONT` в `src/cast.js` (системный, с кириллицей; без `@font-face`).
- **Цвета:** блок палитры сюжета в `src/lib.js` → `pal` (`skyTop…skyHorizon`, `cloud*`, `city*`, `birdInk`).
- **Фигуры:** шестерни `gearPath`, стрелка `pts` в формации `chart`, самолётик `PLANE` и путь `planeAt()`.
- **Стая:** `N` (число птиц), `freeFrac`, `birdLen`, `near` (птицы у камеры), волны `waves`.
- **Темп и длина:** `BPM` и `b(n)` в `src/cast.js`, плюс `src/timeline.js` (bpm, shots, cues).
- **Музыка:** `src/music.js` → `CH`, `CHORDS`, `SUBS`, `score()`, громкость `MIX.trim` (≈ −16 LUFS).

Проверка после правок: `check.cjs` зелёный, `node tools/audio/analyze.cjs .tmp/audio/score.wav --cues`
без промахов, контактный лист глазами.

## Подводные камни

- Headless Chromium обычно рисует WebGL через SwiftShader (CPU): кадр ~100 мс в среднем, до ~450 мс
  на быстрых переходах. Хэши детерминизма стабильны на одной машине и одном бэкенде.
- Плотные буквы вблизи — фактура, на телефоне — чёткие слова. Мелкий текст держать ≥ 100 px.
- Весь текст — выше силуэта города (y < 840) и не на самом ярком свечении солнца.
