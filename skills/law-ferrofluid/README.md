# law-ferrofluid — «Невидимый магнит»

**Закон.** Лужа чёрной магнитной жидкости лежит на полированной стальной плите. Невидимые магниты снизу
«печатают» всё изображение. Сначала жидкость вспухает под формой, потом на долю такта поверхность
разом лопается в острые шипы Розенцвейга (гексагональная решётка), по зеркалу бегут круги. Поле
гаснет, и шипы оседают обратно в гладкое зеркало. Ничего не нарисовано: слова, шестерня, самолётик и
логотип рождаются из жидкости и её отражений. Единственный «нежидкий» текст — гравировка на стальном
борту, её проявляет полоса света.

**Что умеет.**
- Ролик 18–24 с, 1920×1080, 30 fps, с синтезированной музыкой; кадр — чистая функция времени.
- Слова и иконки шипами (до двух строк по ~10 жирных букв), кольца, шестерня, самолётик.
- Макро-открытие: 1 шип → 7 → 19.
- Финальная плашка с гравированным призывом и бесшовной петлёй последнего такта.
- Готовый пример — ролик AiXenix «Бизнес на автопилоте» в папке `example/`.

**Как поставить и собрать свой ролик** (macOS с GPU: ~0,2–0,5 с на кадр):

```bash
cp -R example/ ~/my-ferro-ad && cd ~/my-ferro-ad
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs        # гейт: код выхода 0, WARN допустим
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --samples 24 --sheet --scale 0.5 --out .frames/sheet
zsh deliver.sh                                            # мастер, web, 1280, петля, постер, HTML
```

Нужен `ffmpeg` в PATH. На Linux и Windows WebGL по умолчанию программный, это медленно.
`FILM_GL=gpu` просит у Chromium аппаратный GPU, `FILM_GL=swiftshader` принудительно включает
программный режим.

**Где править.**
- Слова шипами: `src/cast.js`, функция `drawField`, вызовы `letters(g, 'НЕВИДИМАЯ', …)`, `'СИЛА'`,
  `'БИЗНЕС НА'`, `'АВТОПИЛОТЕ'`, `'AiXenix'`.
- Гравировка (слоган, сайт, Telegram, глиф самолётика): `src/cast.js`, функция `engrave`. После правки
  поменяйте `engraveKey`.
- Тайминг событий: таблица `EV` в `src/cast.js`; темп, длительность, шоты и кью — в `src/timeline.js`.
- Цвета студии: палитра `ff*` в `src/lib.js`; где стоят и как светят лампы — `rig` и `band` в
  `src/cast.js`.
- Камера: `camera(T)`, финальный кадр — `FINAL` в `src/cast.js`.
- Музыка: `score()`, `CH` и `MIX.ride` в `src/music.js`. Проверка, что удары совпадают с кью:
  `node tools/audio/analyze.cjs .tmp/audio/score.wav --cues`.

Подробности на английском — в `SKILL.md`. Конвейер (гейт, снимки, рендер) — в
`skills/procedural-film/SKILL.md`, общие заметки по серии — в `skills/aixenix-video/SKILL.md`.
