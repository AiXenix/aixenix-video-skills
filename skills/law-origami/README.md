# law-origami — «Один лист»

**Закон:** один лист A4. Его не режут и не клеят. Он сам складывается на столе: из печатного документа в шестерню, стрелу и бумажный самолётик. Самолётик делает петлю, садится и раскрывается. Сложенная открытка открывается, как книга, и внутри оказывается призыв.

Каждый сгиб, который лист когда-либо сделал, остаётся на бумаге линией. В кадре нет ничего, кроме света, стола и тени листа.

## Что умеет

- Ролик 1920×1080, 30 fps, 21,3 с, 112,5 bpm. Последний такт — бесшовная петля.
- Настоящая симуляция жёсткого оригами на three.js:
  - лист режется на полигоны по линиям сгибов, сгибы складываются и раскладываются стеком;
  - шестерня — замкнутая цепь из 33 панелей;
  - складки копятся и подсвечиваются скользящим светом.
- Оборот с призывом виден только в конце. Первым же сгибом лист складывает верхнюю половину назад и запечатывает оборот между двумя слоями.
- Музыка синтезируется в коде:
  - щипок и бумажный шлепок на каждом сгибе;
  - тики шестерни — гамма маримбы;
  - свист самолёта панорамируется по реальной траектории;
  - колокольный аккорд на раскрытии открытки.
- `example/` — готовая реклама AiXenix «Бизнес на автопилоте».

## Как поставить и сделать свой ролик

Нужны Node 18+, zsh и ffmpeg.

```bash
cp -R skills/law-origami/example my-ad && cd my-ad
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs        # гейт: должен выйти с кодом 0 (WARN по цене кадра — норма)
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --samples 24 --sheet --scale 0.5
zsh deliver.sh                                             # мастер, web, петля, постер, HTML-плеер
```

Файлы появятся в `exports/` и `dist/` под именем папки. Рендер на программном WebGL (SwiftShader) занимает 10–15 минут.

## Где править тексты и цвета

- **Призыв** — `src/cast.js`, функция `backCanvas()`: `'AiXenix'`, `'Бизнес на автопилоте'`, `'aixenix.com'`, `'t.me/aixenix'`, значок `planeIcon()`.
- **Хук на документе** — `src/cast.js`, функция `frontCanvas()`: `'Один лист.'`, `'Ни одного разреза.'`.
- **Цвета** — `src/lib.js`, блок палитры `op*`: стол `opDesk`, бумага `opPaper`, краски призыва `opMagentaInk`, `opVioletInk`, `opCyanInk`, свет `opKey`, `opRim`, `opAccent`.
- **Темп и длительность** — нужно править в трёх местах и держать их согласованными:
  - `BPM` и `TM` в `src/cast.js` (время в долях);
  - `bpm`, `duration`, шоты и метки звука в `src/timeline.js` (в секундах);
  - `BEAT` и `MIX.ride` в `src/music.js`.
- **Камера и свет** — ключи `CAM` и `KEY` в `src/cast.js`. Траектория полёта — `buildFlight()` там же.
- **Музыка** — `CH`, `PROG`, `score()` в `src/music.js`.

После правок прогоните гейт и снимите кадры (`snap.cjs`). Отрендерите звук (`tools/audio/render-audio.cjs`) и проверьте, что удары попадают в метки (`analyze.cjs --cues`).

Подробности по устройству движка и ловушкам — в `SKILL.md`. Общий конвейер — `skills/procedural-film/SKILL.md`.
