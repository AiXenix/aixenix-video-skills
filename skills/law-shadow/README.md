# law-shadow — «Тень»

**Закон:** изображение никогда не рисуется. Все буквы, шестерёнка и бумажный самолётик на стене — настоящие тени
ОДНОЙ парящей скульптуры из офисного хлама: обрывков бумаги, стикеров, кабелей, скрепок, кружек и клавиш.
Скульптура поворачивается под тремя прожекторами, и под точными углами её тени защёлкиваются в слова.

## Что умеет

- Ролик 1920×1080, 30 fps, 21,3 с (8 тактов по 90 bpm), последний такт — бесшовная петля.
- До 7 «раскрытий» из одного объекта: хук («ХАОС?»), значок (шестерёнка), слоган на двух панелях, финальная
  плашка из трёх панелей (бренд + слоган, сайт, самолётик + Telegram).
- Самолётик влетает на панель как настоящая тень плоского пласта обрывков.
- Рядом со словами видны тени узнаваемых вещей (кружка, скрепка, шестерёнка) — доказательство, что это тень.
- Свой саундтрек: гул ламп, трещотка поворота (щелчок на каждые 3° реального угла), удар и аккорд на каждой защёлке.
- Проверка `tools/coverage.cjs` на CPU показывает, что каждая тень совпадает с буквами: дыр 0 %, лишней тени около 0 %.

## Как поставить

Нужны Node 18+, zsh и ffmpeg. Из корня плагина:

```bash
cp -R skills/law-shadow/example my-shadow-ad && cd my-shadow-ad
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 node tools/coverage.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs
zsh deliver.sh
```

`deliver.sh` кладёт в `exports/` мастер, веб-версию, петлю и постер, а в `dist/` — HTML-плеер.

## Как сделать свой ролик

Всё правится в `src/cast.js`, объект `CFG`:

- **Тексты** — `CFG.targets`: цели `haos` (хук), `biz`/`auto` (две половины слогана), `brand` (бренд + слоган),
  `site` (сайт), `tg` (Telegram + самолётик). У каждой цели есть строка `s`, позиция `x, y` (метры на стене),
  высота заглавной `cap`, максимальная ширина `maxW` и шрифт `font`.
- **Значок** — элемент `{ t: 'gear' }` у цели `gear`. Самолётик — элемент `{ t: 'plane' }` и поле `slab` у `tg`.
- **Панели и свет** — `CFG.lights`: положение линзы `pos`, прямоугольник на стене `panel`, оттенок луча `col`.
- **Тайминг** — `MOVES` (повороты и углы защёлок), `LIGHT_ON` (когда включается каждый прожектор), `camAt`
  (камера). Темп и сцены — `src/timeline.js`.
- **Музыка** — `src/music.js`: `CH` (аккорды), `LOCKS`, `CLACKS`, `TURNS`, громкость `MIX.trim`.
- **Цвета** — `PAPERS` (бумага и стикеры), `ITEM_KINDS` (предметы), `uExposure` и `uWallGain` (яркость).

После любой правки текстов, панелей или углов:

1. Запустить `node tools/coverage.cjs` — у всех целей должно быть `ok`.
2. Прогнать гейт `tools/check.cjs`.
3. Посмотреть контакт-лист `tools/snap.cjs --samples 24 --sheet`.

Подробности, тонкости детерминизма и карта файлов — в `SKILL.md`. Общий конвейер — `skills/procedural-film/SKILL.md`.
