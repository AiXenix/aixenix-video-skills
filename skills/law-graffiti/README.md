# Закон «Граффити»

**Закон:** стену расписывают вживую. Бригада баллончиков без рук, валик на шесте и трафареты. Всё, что появляется в кадре, кладёт на стену видимый инструмент. Подтёки бегут вниз по гравитации, трафареты отрываются, бумажный самолётик-трафарет улетает. Ничего не «проявляется» само.

Пример в `example/` — рекламный ролик AiXenix «Бизнес на автопилоте»: 24 с, 1920×1080, 30 fps, бум-бэп, последний такт — бесшовная петля. Сюжет:
1. Стена старой рутины (РУЧНОЙ ВВОД, EXCEL, ЗВОНКИ…) перечёркивается пурпуром.
2. Хук: хромовый throw-up «РУТИНУ — РОБОТАМ».
3. Валик накатывает огромное циановое поле.
4. Дроп: «AiXenix» в четыре баллона, подтёки срываются вниз.
5. Трафареты «БИЗНЕС · НА · АВТОПИЛОТЕ», «aixenix.com».
6. Самолётик срывается со стены, проявляются «t.me/aixenix» и «ИИ-ИНСТРУМЕНТЫ КАЖДЫЙ ДЕНЬ».
7. Проносится электричка, за ней вся стена — финальная плашка.

## Что умеет движок (`example/src/props.js`)
- Распыл: мягкий факел с ореолом и крапом на краю. Краска копится, там, где баллон задержался, ложится гуще.
- Подтёки по нагрузке краски. Их можно задержать до удара и сорвать на дропе.
- Throw-up буквы из «скелетов»: набросок, заливка в два прохода, растяжка, 3D-блок, чёрный и светлый контуры, блики.
- Валик на шесте: ворс, рваные края, краска заканчивается к концу прохода.
- Трафареты с текстом и фигурами: автоматические перемычки, перепыл вокруг карточки, срыв на долю.
- Бетонная стена: опалубка, тяжи, раковины, трещины, ржавые потёки, старые теги под закраской.
- Баллон с конусом распыла и тенью. Электричка как шторка для скрытой склейки.

## Как поставить и сделать свой ролик
Нужны Node.js 18+, ffmpeg и zsh.
```bash
cp -R skills/law-graffiti/example my-graffiti-ad    # имя папки = имя файлов в exports/
cd my-graffiti-ad
npm --prefix tools ci
npx --prefix tools playwright install chromium
FILM_NO_NET=1 node tools/smoke.cjs
FILM_NO_NET=1 zsh tools/q.sh node tools/check.cjs        # гейт: код выхода 0 = зелёный
FILM_NO_NET=1 zsh tools/q.sh node tools/snap.cjs --samples 24 --sheet --scale 0.25
zsh deliver.sh                                           # мастер, web, 1280, петля, постер, HTML
```

## Где править тексты и цвета
Почти всё лежит в `example/src/cast.js`:
- `HERO_WORD` и таблица `GLYPH` — фирменное слово. Буквы задаются скелетами: добавьте свои в `GLYPH`.
- `wordGlyphs(CYR, 'РУТИНУ —' …)` и `'РОБОТАМ'` — хук-фраза. Недостающие буквы добавляются в `CYR`.
- `WORDS` — старые слова рутины на стене.
- `words6` — слоган на трёх трафаретах.
- Вызовы `textStencil('st-site' …)`, `textStencil('st-tme' …)`, `textStencil('st-daily' …)` — сайт, канал, призыв.
- `PLANE` — форма и положение самолётика.

Цвета:
- `SP.PAL` в `src/props.js` — краски;
- таблица `C` в `src/cast.js` — поле, слова, поезд;
- `col: {…}` у каждой работы.

Темп и длина:
- `BPM` и `NBARS` в `src/cast.js`;
- `bpm`, `duration` и `shots` в `src/timeline.js` (один шот = один такт);
- времена событий задаются через `b(такт, доля)`.

Музыка — `src/music.js`: аккорды `CH`/`HARM`, бас `BASS`, хук `RIFF`. Шипение, шлепки трафаретов и поезд строятся из раскладки картинки сами.
